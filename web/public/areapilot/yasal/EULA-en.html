4. Activation and license status

When you enter your license code in the "AreaPilot License" window and press "Activate", the Software checks the license with our server; this needs an internet connection. You can open the window by typing AREAPILOT_LISANS on the AutoCAD command line, or from the "License status and code" link in the "About AreaPilot" window. An activated license has no end date. An internet connection is needed only for activation, "Remove from this computer" and "Reset my devices (email)". In addition, while the Software is running and the computer is online, about once every 7 days it asks our server in the background whether the license has been refunded or cancelled and whether this computer is still registered under it (the "license status check"). If our server clearly reports that the license has been refunded or cancelled, or that this computer is no longer registered under it (for example after the devices were reset), the license is removed from that computer, the Software switches to free mode and you are shown a message saying so. If the check cannot be made (no connection, our server does not answer or cannot be reached), your license keeps working. Activation sends the license code, a random device number the Software creates on first use, and the Software version; the status check sends only the license code and the device number; your drawings, user name and computer name are not sent. The license information is stored on your computer with Windows encryption and, if the record is copied as it is to another computer, it cannot be opened there.

5. Changing, removing and resetting computers

You can remove the license from a computer with "Remove from this computer" in the "AreaPilot License" window and use that place on another computer. This needs an internet connection and can be done up to 3 times in 30 days per license. Uninstalling the Software from Windows does not free the place on our server. If you cannot reach the old computer, "Reset my devices (email)" sends a link to the email address registered for the license; the link is valid for 30 minutes and can be used once. When you confirm the reset, all registered computers are removed, your license code is replaced with a new one and the old code can no longer be activated. Computers activated with the old code switch to free mode at their next license status check made while online; activate the new code on the computers where you want to use it. A license can be reset up to 2 times in 30 days. If you reach these limits, email destek@ostlertech.com.
